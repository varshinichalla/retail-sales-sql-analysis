# Retail Sales SQL Analysis

## Project Overview

This project analyzes retail sales data using SQL to identify revenue trends, evaluate product category performance, and generate insights that can support business decisions.

## Objectives

* Analyze overall retail sales and revenue trends.
* Identify top-performing product categories.
* Summarize sales performance using SQL queries.
* Practice data analysis using SQL Server.

## Tools and Technologies

* SQL Server
* SQL

## Key Analysis Areas

* Total sales and revenue analysis
* Sales performance by product category
* Revenue trend analysis
* Aggregations and filtering using SQL

## Dataset

The project uses a retail sales dataset containing transaction-level sales information.

## Skills Demonstrated

* Data querying and analysis
* SQL aggregations and filtering
* Grouping and sorting data
* Business-focused analytical thinking

## Project Files

SQL query files are included in this repository.

## Conclusion

This project demonstrates how SQL can be used to analyze retail transactions, summarize sales performance, and identify useful business insights.
